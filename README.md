# MŌRA Caféé — versi siap GitHub Pages

Semua file ada di SATU folder (tanpa subfolder), jadi cukup:
1. Buka repositori GitHub -> Add file -> Upload files.
2. Pilih SEMUA file di folder ini (Ctrl+A), termasuk `.nojekyll`, lalu Commit changes.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. Tunggu 1-2 menit, buka https://NAMA-AKUN.github.io/NAMA-REPO/ lalu tekan Ctrl+F5.

Halaman: index, menu, racik, mood, kisah, promo, event, kebun, gizi, galeri, keranjang, lokasi, profil, syarat, privasi.
